# Encore art pipeline

Every 3D asset in Stillnote Encore is generated by a deterministic Blender 4.5
script. There are no downloaded models or image textures. Colour lives in material
base colours from `palette.py`, and baked ambient occlusion is stored in `COLOR_0`.

| Kit | Generator | Output | Contents |
| --- | --- | --- | --- |
| Stage | `build_stage.py` | `public/models/stage-kit.glb` | Arcade lane pads, real piano keys, keybed cabinet, note gems, gold star gems, hold tails, piano-key curbs, metronome bar arches, clef lamp posts |
| World | `build_world.py` (+ `world_*.py`) | `public/models/world-kit.glb` | Floating island base, trees for every season, houses, glasshouse, beacon lighthouse, windmill, ferris wheel, carillon tower, neon tower, festival props, clouds, stillnote crystals ([WORLD_KIT.md](WORLD_KIT.md)) |
| Characters | `build_characters.py` (+ `char_lib.py`) | `public/models/characters.glb` | Coda, the Hush, the Encore airship ([CHARACTERS.md](CHARACTERS.md)) |
| Portraits | `render_portraits.py` | `public/art/portraits/*.png`, `public/art/keyart.jpg` | Dialogue portraits (six expressions) and the key art |

Shared modules:

- `aaa_kit.py` provides bevelled primitives, lathe, extrude and tube sweeps, a ray-traced
  AO bake and the GLB export and summary. It is adapted from the race3D toolkit.
- `palette.py` holds the vivid, warm palette and material finishes (gloss, satin, matte,
  metal, glass) used by every kit.
- `preview.py` renders a labelled contact sheet under the shared warm-key, cool-fill
  and rim lights, using the Standard view transform. `--normalize` shows every root at the
  same size, and `--night` checks the glow materials.
- [`CONTRACTS.md`](CONTRACTS.md) lists the node, pivot and material names and the byte
  budgets the runtime depends on.

Rebuild from the repository root (the Blender path is found by `scripts/blender.mjs`;
set `BLENDER_EXE` to override it):

```sh
npm run assets            # all kits and portraits
npm run assets:stage      # one kit
node scripts/blender.mjs -b --factory-startup --python art/encore/preview.py -- \
  --glb public/models/world-kit.glb --out artifacts/previews/world.png --normalize
node scripts/glb-report.mjs public/models/world-kit.glb   # per-root triangles and materials
```

The `.blend` files next to the scripts are editable snapshots of the last build.
Rerunning a generator overwrites them, so save manual edits under another name first.
